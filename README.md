# 📚 Mini E-Learning Platform

A simple mini e-learning platform built with **Next.js + TypeScript**, featuring course cards, course details, and theme support.  

## 🚀 Features
- Course listing with reusable components  
- Course detail pages  
- Theme provider (light/dark)  
- Built with **Next.js 14** and **TypeScript**  

## 📦 Installation

Clone the repository:
```bash
git clone https://github.com/harunkaruga/mini-e-learning-platform.git
cd mini-e-learning-platform
````

Install dependencies:

```bash
npm install --legacy-peer-deps
```

(or with pnpm)

```bash
pnpm install
```

## ▶️ Running the Project

Start the development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:3000
```

## 🏗️ Build for Production

```bash
npm run build
npm start
```

## 🌍 Deployment (Vercel)

This project is ready for **Vercel deployment**.

1. Go to [Vercel](https://vercel.com/) and log in with GitHub.
2. Import this repository (`mini-e-learning-platform`).
3. Click **Deploy**.
4. Vercel will auto-detect Next.js and set everything up.
5. After deployment, your app will be live on a free `.vercel.app` domain.
